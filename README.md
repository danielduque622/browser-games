# Browser Games

A collection of browser-based games — no build tools, no dependencies, no server required. Each game is a single self-contained HTML file.

## Games

### Guitar Blaster
A top-down space shooter where you control a ship with your mouse and blast waves of enemies across multiple levels.

- Move your ship by moving the mouse
- Click to fire lasers
- Survive enemy waves to advance levels
- Boss fight every 3rd level
- Four enemy types: Grunt, Charger, Swarmer, and Boss

### Tic Tac Toe
Classic two-player Tic Tac Toe with score tracking. Scores persist across rounds within the same session.

- Two-player, take turns clicking squares
- Score is tracked across resets
- First to three in a row wins

## How to Play

Open any game directly in your browser — no installation needed:

```
open guitar_blaster.html
open tictactoe.html
```

Or just double-click the HTML file in Finder.
